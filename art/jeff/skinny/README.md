# Skinny Jeff, polished

`jeff_skinny_original.blend` is the slim (Boy-package) Jeff from PR #1. `polish_jeff.py` polishes it in place:
layered hair locks, smooth plum grin with teeth (no blood), softer bevels, knit and fabric materials.
Rig, bones and the scare animation are unchanged. Result: `jeff_skinny_polished.blend`, portrait and scare video.

Note: tools/export_jeff.py turns parts with more than 8 vertices into Roblox Balls, so the new hair and grin
need a mesh export path before this goes in game. Do not import into Studio until the designer approves.
